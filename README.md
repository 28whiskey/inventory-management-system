# Inventory Management System
A MySQL-based system to manage products, stock, sales and inventory reports for a small business.
## Features
- Product management (add, search, update)
- Stock tracking and balance
- Sales recording
- Revenue and purchase cost calculation
- Inventory reporting with JOINS and aggregates
## Tech Stack
MySQL | PostgreSQL | VS code | Git

## Setup
Run in order:
1. create_database.sql
2. create_tables.sql
3. insert_data.sql
Then run inventory_report.sql or product_operations.sql
